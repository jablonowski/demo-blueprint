# Arm A — no infrastructure

No overlay. The agent receives `S0.md` and nothing else.

It has no component library, no token package, no styleguide. Every colour, spacing step,
control height, border radius and type size is its own invention, and so is every
component.

This is not a "yolo" arm. The functional and visual requirement is the same precise
document the other arms get, and the Figma frames are the same visual truth. What is
missing is any means of expressing that requirement consistently.

Expect competent, plausible output: the model has strong priors for Material and Tailwind
conventions and will produce something that looks deliberate. That is the point of the
baseline — the failure this evaluation is looking for is not ugliness, it is a hundred
unrelated literals that no one can change afterwards.
